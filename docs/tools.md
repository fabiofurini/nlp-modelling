# Tools

The tools needed before the models: the theory that lets us *interrogate* a
nonlinear solution (convexity, KKT) and the solver commands specific to nonlinear
models. Linear programming theory, the general Gurobi commands and the sensitivity
protocol are in [LP Modelling](https://fabiofurini.github.io/lp-modelling/).
